# MAISON — متجر أزياء إلكتروني احترافي

متجر أزياء كامل مبني بـ **Next.js 16 (App Router) + TypeScript + Tailwind CSS + Drizzle ORM (SQLite)**، مع لوحة تحكم (Admin Dashboard) كاملة تتيح لك إدارة المتجر بالكامل بدون لمس الكود. الطلبات تعمل بنظام **"اطلب الآن + تأكيد هاتفي"** بدون أي بوابة دفع إلكتروني.

---

## 1. المتطلبات

- Node.js 20 أو أحدث
- npm

## 2. التشغيل محلياً (Development)

```bash
# 1) تثبيت الحزم
npm install

# 2) نسخ ملف البيئة (تم إنشاؤه مسبقاً باسم .env، تحقق منه فقط)
cp .env.example .env

# 3) إنشاء جداول قاعدة البيانات
npm run db:push

# 4) تعبئة بيانات تجريبية (منتجات، تصنيفات، ألوان، مقاسات) + إنشاء حساب الأدمن
npm run db:seed

# 5) تشغيل المشروع
npm run dev
```

الموقع سيعمل على: **http://localhost:3000**
لوحة التحكم: **http://localhost:3000/admin/login**

> ملاحظة: قاعدة البيانات مُرفقة بالفعل مُعبّأة ببيانات تجريبية (`data/store.db`) — يمكنك تشغيل `npm run dev` مباشرة بدون إعادة عمل الخطوتين 3 و4 إن أردت البدء فوراً.

---

## 3. حساب الأدمن الافتراضي

بعد تشغيل `npm run db:seed`، بيانات الدخول هي:

- **البريد الإلكتروني:** `admin@maison.ma`
- **كلمة المرور:** `Admin@12345`

**مهم جداً:** غيّر كلمة المرور فوراً بعد أول نشر حقيقي (راجع القسم 7).

---

## 4. إضافة/تعديل المنتجات (بدون فتح الكود)

1. سجّل الدخول إلى `/admin/login`
2. من القائمة الجانبية اختر **"المنتجات" → "إضافة منتج"**
3. عبّئ: الاسم، الوصف، السعر الحالي، السعر الأصلي (اختياري — نسبة الخصم تُحسب تلقائياً)، التصنيف
4. ارفع الصور (يمكن ربط كل صورة بلون معيّن أو تركها لكل الألوان)
5. اختر الألوان والمقاسات المتوفرة وحدد المخزون لكل مقاس
6. فعّل الخيارات المناسبة: **مميز / جديد / الأكثر مبيعاً / منشور**
7. احفظ — المنتج يظهر مباشرة في المتجر

لإضافة ألوان أو مقاسات جديدة أولاً: **"الألوان"** و **"المقاسات"** في لوحة التحكم.
لإضافة تصنيف جديد: **"التصنيفات"**.

## 5. تغيير الشعار وصور الصفحة الرئيسية

- **الشعار واسم المتجر ومعلومات التواصل (هاتف/واتساب/إنستغرام/فيسبوك):** من **"الإعدادات"**
- **عنوان وصورة القسم الرئيسي (Hero) وبانر العروض:** من **"الصفحة الرئيسية"**

كل التغييرات تظهر فوراً في الموقع دون الحاجة لإعادة نشر.

## 6. إدارة الطلبات

- كل الطلبات الواردة تظهر في **"الطلبات"** مع تفاصيل العميل الكاملة
- افتح أي طلب لرؤية المنتجات المطلوبة (مع اللون والمقاس والكمية) ومعلومات التواصل
- غيّر حالة الطلب حسب تقدمك: جديد ← تم التواصل ← مؤكد ← قيد التجهيز ← تم الشحن ← تم التوصيل (أو ملغى)
- عدد الطلبات الجديدة يظهر كإشعار في القائمة الجانبية

---

## 7. إنشاء حساب أدمن جديد (أو تغيير كلمة المرور)

عدّل القيم في ملف `.env`:

```bash
SEED_ADMIN_EMAIL=you@example.com
SEED_ADMIN_PASSWORD=YourNewStrongPassword123
```

ثم:

```bash
npm run db:seed
```

هذا لا يحذف بياناتك الحالية — فقط يتخطى إنشاء الحساب إن كان موجوداً بنفس البريد. لتغيير كلمة مرور حساب موجود بنفس البريد، احذف الحساب أولاً من قاعدة البيانات ثم أعد تشغيل الأمر.

## 8. النشر إلى الإنتاج (Production)

### أي استضافة تدعم Node.js (VPS, Railway, Render, إلخ)

```bash
npm install
npm run build
npm run db:push     # أول مرة فقط، أو بعد أي تعديل على src/db/schema.ts
npm run db:seed     # أول مرة فقط
npm run start        # يشغل السيرفر على المنفذ 3000
```

اضبط متغيرات البيئة على الاستضافة (خصوصاً `SESSION_SECRET` بقيمة عشوائية قوية وطويلة).

### ملاحظة عن قاعدة البيانات

المشروع يستخدم **SQLite** (ملف واحد في `data/store.db`) وهو مناسب جداً للانطلاق وحتى لحجم تجاري متوسط. إذا احتجت لاحقاً للانتقال إلى PostgreSQL أو Supabase (لدعم عدة سيرفرات في نفس الوقت)، فقط:
1. غيّر `dialect` في `drizzle.config.ts` و `src/db/index.ts` إلى Postgres
2. استخدم نفس ملف `src/db/schema.ts` (البنية متوافقة تقريباً بالكامل)

### الصور المرفوعة

الصور التي يرفعها الأدمن تُحفظ في `public/products/`. عند النشر على استضافة بدون تخزين دائم (serverless بحت)، يُفضّل ربط خدمة تخزين سحابي (مثل Cloudflare R2 أو AWS S3).

## 9. البنية التقنية

```
src/
  app/                 صفحات الموقع (Next.js App Router)
    (shop)/shop/       صفحة المتجر
    admin/             لوحة التحكم (محمية بمصادقة)
    api/               نقاط الـ API (طلبات، أدمن، رفع صور)
    product/[slug]/    صفحة تفاصيل المنتج
    cart/, checkout/, order-confirmation/
  components/
    ui/                مكونات أساسية (أزرار، شارات...)
    layout/            Navbar, Footer, WhatsApp
    shop/              مكونات المتجر (بطاقة منتج، معرض صور، سلة)
    home/              مكونات الصفحة الرئيسية
    admin/             مكونات لوحة التحكم
  context/             Cart + Toast (React Context)
  db/                  Schema وإعداد قاعدة البيانات (Drizzle)
  lib/
    data/              طبقة الوصول لقاعدة البيانات (Products, Orders, Settings)
    auth.ts            جلسات الأدمن (JWT)
    utils.ts           دوال مساعدة (السعر، الخصم، التحقق من الهاتف...)
scripts/seed.ts        سكريبت البيانات التجريبية
```

**التقنيات المستخدمة:**
- Next.js 16 (App Router, Server Components)
- TypeScript
- Tailwind CSS 4
- Drizzle ORM + better-sqlite3 (بديل موثوق لـ Prisma هنا)
- jose (جلسات JWT خفيفة للأدمن)
- Zod (التحقق من صحة البيانات في الـ API)
- lucide-react (الأيقونات)
- خطوط عربية مُحمّلة محلياً عبر Fontsource (Tajawal + El Messiri)

**مميزات تقنية أساسية:**
- RTL كامل للعربية
- SEO: metadata لكل صفحة + JSON-LD للمنتجات
- الأداء: Server Components، lazy loading للصور، skeleton loading
- الأمان: جلسات موقّعة (JWT)، مسارات الأدمن محمية عبر middleware، تحقق Zod على كل مدخلات الـ API
- السلة محفوظة في localStorage (متوافقة مع SSR بدون مشاكل hydration)
- المخزون يُخصم تلقائياً عند كل طلب
